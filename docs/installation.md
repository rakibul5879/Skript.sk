# Installation

## Requirements

A Minecraft server and a compatible Skript installation are required.

Some scripts may require additional addons or plugins. Check each script's own documentation.

## Install a Script

1. Download the required `.sk` file.
2. Upload it to `plugins/Skript/scripts/`.
3. Start the server, or reload the script using `/sk reload <script-name>`.
4. Check the console for parsing errors.
5. Test commands, permissions, GUI interactions, and edge cases before enabling it for players.

## Updating

Back up the existing script and its configuration before replacing it.

Read the changelog for breaking changes, then reload and test the updated version.

## Troubleshooting

- Confirm the installed Skript version matches the script's requirements.
- Install every required addon at a compatible version.
- Read the first parsing error in the server console.
- Check indentation and file encoding if you edited the script.
- Report the Minecraft, server, Java, Skript, and addon versions when requesting help.
